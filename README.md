# Next.js 14 App Router + TypeScript + Tailwind (Clean Starter)

Minimal, production-ready starter configured with:

- Next.js App Router (app/)
- TypeScript
- Tailwind CSS
- Global Inter font
- Light theme default, white background, deep-blue primary (#1e3a8a)

Getting started

1. Install dependencies:

```bash
npm install
```

2. Run dev server:

```bash
npm run dev
```

Notes

- Tailwind config is in `tailwind.config.ts`.
- Global styles are in `styles/globals.css`.
- App Router root layout is `app/layout.tsx` and the homepage is `app/page.tsx`.
